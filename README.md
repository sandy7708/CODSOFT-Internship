#CODSOFT 

AI Internship Projects

Description

This repository contains the AI projects completed during my internship. The projects demonstrate basic concepts of Artificial Intelligence, Python programming, and problem-solving.

Projects

1. Rule-Based Chatbot

A simple chatbot that responds to user inputs using predefined rules and conditional statements.

2. Tic-Tac-Toe AI

An AI-based Tic-Tac-Toe game where the computer makes intelligent moves using the Minimax algorithm.

3. Recommended System

A recommendation system that suggests items based on user preferences using basic recommendation techniques.

Technologies Used

- Python
- Jupyter Notebook
- Google Colab
- Pandas
- NumPy

How to Run

1. Open the Jupyter Notebook or Google Colab.
2. Install the required libraries.
3. Run all the cells.
4. Follow the instructions in each notebook.

Outcome

These projects helped me improve my understanding of AI concepts, Python programming, recommendation systems, and problem-solving skills.
